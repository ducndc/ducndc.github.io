Detailed Description

The event loop is a programming construct that waits for and dispatches events in a program.

It works by making a request to some "event provider" (which generally blocks the request until an event has arrived), and then it calls the relevant event handler (i.e.: dispatches the event).

The event provider used by the event loop follows the file interface, which can be selected or 'polled' (the Unix system call, not actual polling). The event loop operates asynchronously with the event originator.

When the event loop forms the central control flow construct of a program, as it often does, it may be termed the main loop or main event loop. This title is appropriate because such an event loop is at the highest level of control within the program.
