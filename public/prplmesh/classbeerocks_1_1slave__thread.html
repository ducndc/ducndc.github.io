◆ m_cmdu_server

std::unique_ptr<CmduServer> beerocks::slave_thread::m_cmdu_server
private
Note
There is a difference in the use of a client socket the Agent holds to another server (Broker/Backhaul Manager/Platform Manager) and clients that are connected to the Agent CMDU server (AP Manager/Monitor). On a client we hold, we need to use the internal client object function send()/forward(), whereas, for clients that are connected to the Agent, the Agent only hold their file descriptor so for sending them a CMDU, need to use m_cmdu_server send_cmdu()/forward_cmdu() which this class have wrapper function for. CMDU server to exchange CMDU messages with clients through socket connections.
