void beerocks::net::InterfaceStateMonitor::set_handler ( const StateChangedHandler &  handler)
inline

Sets the state-changed event handler function.

Sets the callback function to handle network interface state changes. Use nullptr to remove previously installed callback function.

If a handler is set, it will be called back whenever any of the network interfaces changes its state to or from the up-and-running value.

Parameters
handlerState change handler function (or nullptr).
