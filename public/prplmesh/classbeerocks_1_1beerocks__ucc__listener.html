◆ send_reply()

bool beerocks_ucc_listener::send_reply ( int  fd,
const std::string &  err_string = std::string() 
)

Sends second WFA-CA reply message to UCC client.

This method must be invoked when the processing of a WFA-CA command is complete, in order to send the second reply to UCC client.

The status code included in the reply is eWfaCaStatus::COMPLETE on success and eWfaCaStatus::ERROR otherwise (i.e.: if given error description is not empty).

Parameters
[in]fdFile descriptor of the socket connection the command was received through. The reply to the command will be sent through this connection too.
[in]err_stringEmpty on success and error description otherwise.
Returns
true on success and false otherwise.
