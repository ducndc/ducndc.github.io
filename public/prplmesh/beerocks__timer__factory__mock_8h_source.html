20 // Google Mock cannot mock a factory method that returns a non copyable return value.
21 // To work around this, we add an indirection through a proxy method.
22 // Production code will use the overridden method and unit tests will set expectations in the
23 // mocked helper method instead.

25 {
26 return std::unique_ptr<beerocks::net::Timer<>>(create_instance_proxy());
