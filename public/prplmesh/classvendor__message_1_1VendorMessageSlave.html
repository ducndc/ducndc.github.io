Handles CMDU message received from broker.

This handler is slightly different than the handler for CMDU messages received from other processes as it checks the source and destination MAC addresses set by the original sender. It also filters out messages that are not addressed to the controller.

Parameters
iface_indexIndex of the network interface that the CMDU message was received on.
