Detailed Description

Channel information.

Used in band_info structure as each band contains a map of supported channels.

Information obtained with NL80211_CMD_GET_WIPHY command through a NL80211 socket. See NL80211_FREQUENCY_ATTR_* in <linux/nl80211.h> for a description of each field.
