◆ attach()

HALState bwl::dummy::base_wlan_hal_dummy::attach ( bool  block = false)
overridevirtual

Attach to the WLAN hardware/middleware.

Unless the "block" argument is set to "true", the implementation should be non-blocking. If the internal implementation may block, the state should be set to "Initializing" and the upper layer will call this method again until the state will change to "Operational" or "Failed".

Parameters
[in]blockExecute in non-blocking (default) or blocking mode.
Returns
The state of the attach process.
