void beerocks::net::BridgeStateMonitorImpl::handle_netlink_event ( const nlmsghdr *  msg_hdr)
private

Netlink event handler function.

Parses messages received through the Netlink socket connection to extract information about bridge changes out of them.

If the type of the Netlink message is RTM_NEWLINK or RTM_DELLINK then reads the interface index and the IFLA_MASTER attribute and notifies a change in the bridge state.

msg_hdrNetlink message header struct containing Netlink event.
