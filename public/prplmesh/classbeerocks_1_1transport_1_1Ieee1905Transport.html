◆ forward_packet()

bool beerocks::transport::Ieee1905Transport::forward_packet ( Packet &  packet)
private

forward a 1905.1 packet.

Basically a wrapper to forward_packet_single, which also takes into account the reliable multicast procedure - according to section 15.1 in the Multi-AP specification, a reliable multicast transmission includes sending the packet with the relay bit set to a multicast address once, and once for each discovered Multi-AP agent in the network as unicast with the same MID and the relay bit unset.

Parameters
packetpacket to forward
Returns
true on success
false on failure (one or more packets failed in transmission)
