Detailed Description

Link metrics collector interface.

This is a C++ interface: an abstract class that is designed to be specifically used as a base class and which derived classes (implementations) will override each pure virtual function.

Known implementations: ieee802_3_link_metrics_collector and ieee802_11_link_metrics_collector.
