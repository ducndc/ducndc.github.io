Detailed Description

The CMDU client is a component to send and receive CMDU messages between local processes.

In this implementation of the

See also
CmduClient interface, the connection between communicating processes must have already been established with a server socket. The framing protocol used is defined by the CMDU parser and serializer objects given constructor.

Closes connection between client and server socket.

Removes handlers for events on this connection in the event loop (optionally, depending on given parameter value). Marks the connection as terminated so it cannot be used from now on (as a consequence, calls to method for sending a message to the server will fail).

◆ m_buffer

beerocks::net::BufferImpl<message::MESSAGE_BUFFER_LENGTH> beerocks::CmduClientImpl::m_buffer
private

Buffer to hold data received through the socket connection. If connection uses a stream-oriented socket, it needs its own buffer to hold received data. A stream-oriented socket provides a stream of bytes, it is not message-oriented, and does not provide boundaries. One write call could take several read calls to get that data. Data from several write calls could be read by one read call. And anything in between is also possible. If connection uses a message-oriented socket instead, this buffer and the code that uses it is also valid.
