◆ recalculate_byte_units()

uint32_t monitor_stats::recalculate_byte_units ( uint64_t  bytes) const
private

Recalculate single value of byte units to support R2 spec.

R2 specification require associated station traffic stats to be in KB units while R1 only support Byte units. The monitor produces the value in Byte units so it need to be recalculated according to the controller expectation.

Parameters
[in]bytesNumber of bytes to recalculate
Returns
Recalculated value of the bytes
