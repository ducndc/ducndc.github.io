Generates client-connected event for already connected clients. This is used to overcome a scenario where clients that are already connected are not known to prplmesh and "missed" the "connected" event for them. This scenario can happen due to prplmesh unexpected restart, son-slave unexpected restart and/or during development when prplmesh is intentionally restarted.

Parameters
[out]is_finished_all_clients- Is generation for all clients complete
[in]max_iteration_timeout- The time when thread awake time expires and function must return
Returns
true if finished generating, false otherwise

virtual bool bwl::mon_wlan_hal::pre_generate_connected_clients_events ( )
pure virtual

The generate connected clients events can be called several times by an agent (after the agent re-establishes connection to a controller). To support this we need to be able to clear the "progress" of the client's events generation before calling the generate_connected_clients_events API repetitively. The API resets the lists of "handled_clients" and "completed_vaps" that manage the already handled clients and VAPs.

Update station statistics for multiple stations on one VAP.

The default implementation preserves the existing per-STA polling path. HALs may override it to update the requested VAP stations in bulk.

[in]sta_macsStation MAC addresses to update.

[in]is_read_unicastUse unicast TX packet counter when true.
