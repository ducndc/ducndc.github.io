◆ m_buffer

beerocks::net::BufferImpl<broker_buffer_size> beerocks::btl::BrokerClientImpl::m_buffer
private

Buffer to hold data received through the socket connection. If connection uses a stream-oriented socket, it needs its own buffer to hold received data. A stream-oriented socket provides a stream of bytes, it is not message-oriented, and does not provide boundaries. One write call could take several read calls to get that data. Data from several write calls could be read by one read call. And anything in between is also possible. If connection uses a message-oriented socket instead, this buffer and the code that uses it is also valid.
