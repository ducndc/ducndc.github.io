int beerocks::wbapi::AmbiorixConnection::read ( )

Read data from the file descriptor of the connection context. Typically the backend parses the received data and dispatches to the correct callbacks if needed.

This function is typically called whenever your eventloop detects that data is available for read on the connection context's file descriptor.

Returns
