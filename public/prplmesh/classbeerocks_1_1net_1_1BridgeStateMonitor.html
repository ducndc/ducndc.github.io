void beerocks::net::BridgeStateMonitor::set_handler ( const StateChangedHandler &  handler)
inline

Sets the state-changed event handler function.

Sets the callback function to handle bridge state changes. Use nullptr to remove previously installed callback function.

If a handler is set, it will be called back whenever a bridge state changes, either because a new interface is added to the bridge or because an interface is removed from the bridge.

Parameters
handlerState change handler function (or nullptr).
