bool bwl::nl80211_client::SurveyInfo::get_channel_utilization ( uint8_t &  channel_utilization) const

Gets channel utilization.

The channel utilization is defined as the percentage of time, linearly scaled with 255 representing 100%, that the AP sensed the medium was busy. When more than one channel is in use for the BSS, the channel utilization value is calculated only for the primary channel.

This percentage is computed using the formula: channel_utilization = (channel busy time * 255) / channel on time

Parameters
[out]channel_utilizationChannel utilization value on success and 0 if it cannot be obtained.
Returns
True on success and false if there is no channel in use or time on is zero (i.e.: no data available) or time busy is greater than time on.
