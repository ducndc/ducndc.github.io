Detailed Description

Per-BSS configuration received via WSC/1905 TLVs.

Holds all data needed to (re)configure a single AP BSS on the Agent side. It aggregates attributes parsed from:

  • WSC M2 TLV and it's "Encrypted Settings" (e.g. SSID, keying)
  • Agent AP MLD Configuration TLV
  • RSN Parameters Configuration TLV
