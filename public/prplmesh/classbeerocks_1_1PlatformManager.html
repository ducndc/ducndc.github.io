◆ check_wlan_params_changed()

bool beerocks::PlatformManager::check_wlan_params_changed ( )
private

Checks if WLAN parameters have changed.

For each of the slaves, performs a check on the band_enabled and channel parameters and, if changed, sends a ACTION_PLATFORM_WLAN_PARAMS_CHANGED_NOTIFICATION message to the slave including the new settings.

Returns
true if WLAN parameters have changed for any of the slaves.
