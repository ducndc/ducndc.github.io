Detailed Description

Timer factory interface.

Classes that need to create timer objects must use a factory to do so, instead of creating the timers directly (to avoid dependencies on OS resources, like a timer file descriptor). Such factory will be provided as a dependency so it can be mocked while unit testing. A timer factory mock will return timer mocks whenever an expectation of a call to create_instance() is satisfied.
