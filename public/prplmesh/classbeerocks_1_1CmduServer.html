Detailed Description

The CMDU server is a component to send and receive CMDU messages between local processes.

This component acts as the server side end-point of the connection between communicating processes while the

See also
CmduClient plays the client role.

Users of this component register a handler to process received CMDU messages and send CMDU messages in response.

Set the client name on EventLoop file descriptor handler.

At a client connection it is not possible to know who that client is. This function allows setting the file descriptor name in the EventLoop handlers later on when the client identified so in case of EventLoop error or a client disconnect event it will be possible to know on which client the event has occurred.
