bool son::monitor_radio_node::SRadioStats::vap_stats_available = false

Flag that signals if last VAP statistics read contain meaningful data for at least one VAP. This flag is updated whenever VAP statistics are updated. The term "available" in this context means that both transmitted and received bytes are set to a value greater than 0.
